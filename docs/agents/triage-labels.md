# Triage labels

When triaging an item, append its label in backticks to the entry or its final table cell.
Replace the previous triage label when the status changes.

| Label | Meaning |
| --- | --- |
| `needs-triage` | A maintainer needs to evaluate the item. |
| `needs-info` | The reporter needs to provide more information. |
| `ready-for-agent` | The item is specified well enough for an agent to implement. |
| `ready-for-human` | The item requires human implementation. |
| `wontfix` | The maintainer has decided against pursuing the item. |
